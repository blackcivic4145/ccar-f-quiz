# CCAR-F 模擬問題集

CCAR-F（Claude Certified Architect - Foundations）の学習用に作成した、4択形式の模擬問題集です。ブラウザだけで動作し、インストールは不要です。

▶ [ここで開く（GitHub Pages）](https://blackcivic4145.github.io/ccar-f-quiz/)

## 特徴

- 全150問収録（Agentic Architecture / Claude Code 設定・ワークフロー / プロンプトエンジニアリング・構造化出力 / ツール設計・MCP統合 / コンテキスト管理・信頼性）
- 出題数を選ぶと、公式の出題比率（27% / 20% / 20% / 18% / 15%）を維持したままランダム抽出
- 制限時間120分のカウントダウン付き（超過時は自動採点）
- 各問題にパターン別の概念図（フローチャート）と平易なキャプションを表示
- 回答後は正誤・解説に加えて図解を用いたおさらいを表示
- 分野別成績・誤答一覧つきの結果画面

## 使い方

`index.html` をブラウザで開くだけで動作します。サーバーやビルドは不要です。

## 免責事項

このデータはClaude(Anthropic)が一般知識をもとに作成した非公式の学習用問題であり、実際の試験内容・出題を保証するものではありません。
